# PrepOS 💻🚀

PrepOS is a sleek, modern, and developer-centric interview preparation dashboard built to help you land your dream tech role. Designed with a premium dark-mode aesthetic (inspired by platforms like LeetCode), it acts as your personal command center for technical interviews, system design practice, and behavioral mock sessions.

## ✨ Features

- **🎯 Interactive Practice Modules**: Keep track of your progress across Data Structures & Algorithms, System Design, Behavioral Mocks, and Resume Grading.
- **🔥 Daily Streaks & Analytics**: Stay motivated with daily streaks, readiness scores, and visual progress indicators to ensure you're always improving.
- **⚡ "Question of the Day" Terminal**: A beautiful, terminal-style component that serves up a daily coding challenge to keep your problem-solving skills sharp.
- **📅 Upcoming Agenda**: Seamlessly track your upcoming mock interviews, resume review syncs, and practice sessions in one organized view.
- **🎨 Premium UI/UX**: Built with a cyberpunk/developer-focused aesthetic featuring glowing accents, glassmorphism, and responsive design.

## 🛠️ Tech Stack

- **Frontend Framework:** [React 18](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites
Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository
```bash
git clone https://github.com/your-username/prepos.git
```

2. Navigate to the project directory
```bash
cd prepos
```

3. Install the dependencies
```bash
npm install
```

4. Start the development server
```bash
npm run dev
```

5. Open your browser and navigate to the URL provided in your terminal (usually `http://localhost:5173`).
